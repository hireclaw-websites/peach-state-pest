# 🍑 Peach State Pest Control

A professional pest control company website for Atlanta, Georgia.

## Live Website

**URL:** https://peach-state-pest.pages.dev

## About

Peach State Pest Control is a family-owned business serving Georgia since 1995. This website showcases our services, pest library, and provides an easy way for customers to request free inspections.

## Services

- **Termite Control** - Comprehensive termite inspection, treatment, and prevention
- **Rodent Removal** - Humane and effective rodent control
- **Insect Control** - Targeted treatments for ants, roaches, spiders, mosquitoes
- **Prevention Plans** - Year-round pest prevention with quarterly maintenance
- **Commercial Services** - Professional pest management for businesses
- **Eco-Friendly Options** - Green pest control solutions

## Features

- 🎨 Southern charm design with peach accents
- 📱 Fully responsive design
- 🔍 Interactive pest library
- 📞 Contact form with validation
- ⚡ Fast, static site deployment on Cloudflare Pages
